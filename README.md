# Number Guessing Game

This is a project made in the Blazor framework for a software development course.\
In the game, the system generates a random number for you to guess in a limited number of tries. It then records your score of how many consecutive games you've won, and posts this to an internal leaderboard.\
The game runs on C# code, and using the Blazor .NET framework, displays this on a webpage, with the ability to view different versions of the game and leaderboard.
